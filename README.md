# Лабораторна 4: зіставлення ознак, RANSAC, панорама

Запуск (з папки lab04):  python src/main.py

Потрібно: Python 3, opencv-python (з SIFT, версія >= 4.4), numpy, matplotlib.

Дані (папка data/ — створіть її поруч із src/ і покладіть туди свої фото; у архіві її немає, бо оригінали важкі):
- pair_1.jpg, pair_2.jpg  - пара сусідніх кадрів для частин A-C (перекриття ~40 %)
- frame_1.jpg ... frame_N.jpg - кадри панорами (частина D); порядок у файлах може бути будь-який,
  опорний кадр і ланцюжок гомографій обираються автоматично за кількістю узгоджених точок
- other_*.jpg - додаткові кадри для частини E (випадки відмови)

Щоб запустити на своїх фото: замініть pair_*.jpg та frame_*.jpg (для частини E потрібні other_599/600/601/602/603.jpg
або зменшіть набір у src/part_e.py).

Результати: results/*.csv, figures/*.

Відповідність файлів оригінальним знімкам:
- pair_1.jpg = 1000018588.jpg, pair_2.jpg = 1000018589.jpg
- frame_1.jpg = 1000018588.jpg, frame_2.jpg = 1000018589.jpg, frame_3.jpg = 1000018602.jpg, frame_4.jpg = 1000018601 (.webp треба зберегти як .jpg)
- other_599.jpg, other_600.jpg, other_601.jpg, other_602.jpg, other_603.jpg = 1000018599, ...600, ...601, ...602, ...603
Кадри автоматично зменшуються до ширини 1000 px, тому оригінальний розмір (3072x4080) не змінюйте.
